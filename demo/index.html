deskpal demo

This page is served under a strict Content Security Policy with no inline scripts. The assistant in the corner boots from the JSON block in the head and answers from the docs in demo/docs/.

Try asking:

  • How do I add deskpal to my site?
  • What CSP does it need?
  • Can I use my own character?
  • How do I use Ollama?
  • What's the capital of France? (it shouldn't know)

Drag the character around, leave it alone for a while, or hide it. It remembers where you put it.

On the first question it asks to download about 110 MB, once. After that it answers on your device by quoting the docs, with the answer highlighted. Say no and it shows the matching sections instead.

To try written answers from a model you run, start Ollama and set "adapter": "openai-compatible", "endpoint": "http://localhost:11434/v1", "model": "qwen3:0.6b" in the config block.
